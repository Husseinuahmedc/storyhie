# Project instructions

Build the app described in IMPLEMENTATION.md. Use DESIGN.md and the screenshots in references/ for visual decisions.

- Use Next.js App Router, TypeScript, Tailwind CSS and browser Canvas.
- Keep the interface in English and support Arabic and English story text.
- Keep uploaded user images and drafts in the browser. Only a search query or a validated Spotify track URL may go to its catalog endpoint.
- Keep manual entry functional without secrets, accounts or a database. Treat Figma interactions as design references and implement the actual behavior.
- Verify lint, type checking and production build. Test the mobile workflow and the PNG export. Report any browser or provider checks that could not run.
- Do not publish or deploy unless requested. Never commit secrets.
